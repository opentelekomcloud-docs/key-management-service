API Overview
============

You can use all functions of DEW by calling its APIs.

KMS APIs for Managing Encryption Keys
-------------------------------------

+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| API                                                            | Description                                                                                                                                                                      |
+================================================================+==================================================================================================================================================================================+
| :ref:`Creating a CMK <kms_02_0012>`                            | Create a CMK.                                                                                                                                                                    |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Enabling a CMK <kms_02_0013>`                            | Enable a CMK. Only an enabled CMK can be used.                                                                                                                                   |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Disabling a CMK <kms_02_0014>`                           | Disable a CMK. A disabled CMK cannot be used.                                                                                                                                    |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Scheduling the Deletion of a CMK <kms_02_0015>`          | Schedule the deletion of a specific key. The deletion can be scheduled 7 to 1,096 days in advance. After a key is deleted, the data encrypted using the key cannot be decrypted. |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Canceling the Scheduled Deletion of a CMK <kms_02_0016>` | Cancel a scheduled deletion of a key. Once the deletion is cancelled, the key can be used.                                                                                       |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the List of CMKs <kms_02_0017>`                 | Obtain the list of all keys.                                                                                                                                                     |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying a Public Key <showpublickey>`                   | Query the public key information.                                                                                                                                                |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Information About a CMK <kms_02_0018>`      | Obtain details of a specified key.                                                                                                                                               |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating a Random Number <kms_02_0019>`                  | Generate a 512-bit random number.                                                                                                                                                |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating a DEK <kms_02_0020>`                            | Create a DEK. A returned result includes the plaintext and the ciphertext of a DEK.                                                                                              |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating a Plaintext-Free DEK <kms_02_0021>`             | Create a plaintext-free DEK, that is, the returned result of this API includes only the ciphertext of the DEK.                                                                   |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Encrypting a DEK <kms_02_0022>`                          | Use a specified CMK to encrypt a DEK.                                                                                                                                            |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Decrypting a DEK <kms_02_0023>`                          | Use a specified CMK to decrypt a DEK.                                                                                                                                            |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Number of Instances <kms_02_0024>`          | Obtain the number of created CMKs, excluding the default master keys.                                                                                                            |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Quota of a User <kms_02_0025>`              | Query the total quota of CMKs available and the usage information, excluding the default master keys.                                                                            |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Changing the Alias of a CMK <kms_02_0026>`               | Change the alias of a CMK.                                                                                                                                                       |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Changing the Description of a CMK <kms_02_0027>`         | Change the description of a CMK.                                                                                                                                                 |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating a Grant <kms_02_0028>`                          | Grant a user the permissions to perform operations on a specific key.                                                                                                            |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Revoking a Grant <kms_02_0029>`                          | Revoke the key operation permissions granted to a user.                                                                                                                          |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Retiring a Grant <kms_02_0030>`                          | Retire the granted key operation permissions.                                                                                                                                    |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying Grants on a CMK <kms_02_0031>`                  | Obtain the grants on a key.                                                                                                                                                      |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying Grants That Can Be Retired <kms_02_0032>`       | Obtain the grants that can be retired.                                                                                                                                           |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Obtaining CMK Import Parameters <kms_02_0035>`           | Obtain necessary parameters to import a key, including an import token and a public key.                                                                                         |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Importing CMK Material <kms_02_0036>`                    | Import the material of a key.                                                                                                                                                    |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Deleting CMK Material <kms_02_0037>`                     | Delete the material of a key.                                                                                                                                                    |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying CMK Instances <kms_02_0042>`                    | Use tag filtering to query the detailed information of a CMK.                                                                                                                    |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying CMK Tags <kms_02_0043>`                         | Query tags of a specified key.                                                                                                                                                   |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying Project Tags <kms_02_0044>`                     | Query all tag sets of a project.                                                                                                                                                 |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Adding or Deleting CMK Tags in Batches <kms_02_0045>`    | Add or delete key tags in batches.                                                                                                                                               |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Adding a CMK Tag <kms_02_0046>`                          | Add tags to a key.                                                                                                                                                               |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Deleting a CMK Tag <kms_02_0047>`                        | Delete tags from a key.                                                                                                                                                          |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying All API Versions <kms_02_0048>`                 | ``-``                                                                                                                                                                            |
+----------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

CSMS APIs

+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Name                                                                           | Description                                                                                                                                                                                                                                                                                |
+================================================================================+============================================================================================================================================================================================================================================================================================+
| :ref:`Creating a Secret <kms_02_0214>`                                         | Create a secret and store the secret value in the initial secret version.                                                                                                                                                                                                                  |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Secret List <kms_02_0215>`                                  | Obtain all the secrets created by the current user in the current project.                                                                                                                                                                                                                 |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying a Secret <kms_02_0216>`                                         | Query a specified secret.                                                                                                                                                                                                                                                                  |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Updating a Secret <kms_02_0217>`                                         | Update the metadata of a specified secret.                                                                                                                                                                                                                                                 |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Deleting a Secret Immediately <kms_02_0218>`                             | Delete a specified secret. The deleted secret cannot be restored.                                                                                                                                                                                                                          |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Restoring a Secret <kms_02_0219>`                                        | Restore a secret by uploading the secret backup file.                                                                                                                                                                                                                                      |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Downloading a Secret Backup <kms_02_0220>`                               | Download the backup file of a specified secret.                                                                                                                                                                                                                                            |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating a Scheduled Secret Deletion Task <kms_02_0221>`                 | Create a scheduled task to delete a secret after 7 to 30 days.                                                                                                                                                                                                                             |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Canceling a Scheduled Secret Deletion Task <kms_02_0222>`                | Cancel the scheduled deletion task of a secret. The secret will be changed to the available state.                                                                                                                                                                                         |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating a Secret Version <kms_02_0223>`                                 | Create a new version for the specified secret to encrypt and store the new value of the secret. By default, The latest secret version in **SYSCURRENT** state. The previous version is in the **SYSPREVIOUS** state. You can configure **VersionStage** to overwrite the default settings. |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Secret Version List <kms_02_0224>`                          | Obtain the version list of a specific secret.                                                                                                                                                                                                                                              |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Secret Version and Value <kms_02_0225>`                     | Query the information about a specified secret version and the plaintext secret value in the version. Only secrets in the **Enabled** state can be queried.                                                                                                                                |
|                                                                                |                                                                                                                                                                                                                                                                                            |
|                                                                                | The value of the latest secret version can be obtained via **/v1/{project_id}/secrets/{secret_name}/versions/latest**. (Set **{version_id}** in the URL of the current API to **latest**).                                                                                                 |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Updating the Version Status of a Secret <kms_02_0226>`                   | Update the version status of a secret.                                                                                                                                                                                                                                                     |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Status of a Secret Version <kms_02_0227>`                   | Query the version of a specified secret version status tag.                                                                                                                                                                                                                                |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Deleting the Version Status of a Secret <kms_02_0228>`                   | Delete the status of a specified secret version.                                                                                                                                                                                                                                           |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying a Secret Instance <kms_02_0229>`                                | Query a secret instance. Filter user secrets by tag and return the secret list.                                                                                                                                                                                                            |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Batch Adding or Deleting Secret Tags <kms_02_0230>`                      | Add or delete secret tags in batches.                                                                                                                                                                                                                                                      |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying a Secret Tag <kms_02_0231>`                                     | Query secret tags.                                                                                                                                                                                                                                                                         |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Adding a Secret Tag <kms_02_0232>`                                       | Add a secret tag.                                                                                                                                                                                                                                                                          |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Deleting a Secret Tag <kms_02_0233>`                                     | Delete a secret tag.                                                                                                                                                                                                                                                                       |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying Project Tags <kms_02_0234>`                                     | Query all secret tags of a user in a specified project.                                                                                                                                                                                                                                    |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Creating an Event <createsecretevent>`                                   | Create an event that can be configured on one or more secrets. When an event is enabled and the basic event type contained in the event is triggered on the secret, the cloud service sends the corresponding event notification to the notification topic specified by the event.         |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying an Event <showsecretevent>`                                     | Query information about a specified event.                                                                                                                                                                                                                                                 |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Querying the Event List <listsecretevents>`                              | Obtain all events created by the current user in the project.                                                                                                                                                                                                                              |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Updating an Event <updatesecretevent>`                                   | Update the metadata of a specified event. The following metadata can be updated: event enabling status, basic type list, and notification topic.                                                                                                                                           |
+--------------------------------------------------------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| :ref:`Deleting an Event Immediately <deletesecretevent>`                       | Delete a specified event. The deleted event cannot be restored. An event cannot be deleted if it is referenced by a secret. Disassociate the event from the secret.                                                                                                                        |
