Querying a Secret Instance
==========================

Function
--------

-  This API is used to query a secret instance, filter user secrets by tag, and return the secret list.

Debugging
---------

You can debug this API in . Automatic authentication is supported. API Explorer can automatically generate SDK code examples and provide the SDK code example debugging.

URI
---

POST /v1/{project_id}/csms/{resource_instances}/action

.. table:: **Table 1** URI parameters

   +--------------------+-----------+--------+---------------------------------------------------------+
   | Parameter          | Mandatory | Type   | Description                                             |
   +====================+===========+========+=========================================================+

   +--------------------+-----------+--------+---------------------------------------------------------+
   | project_id         | Yes       | String | Project ID.                                             |
   +--------------------+-----------+--------+---------------------------------------------------------+

Example Request
---------------

Obtain all secret instances containing the **key1-value1** tag in the current project.

.. code-block:: text

   POST https://{csms_endpoint}/v1/{project_id}/csms/resource_instances/action
   {
     "action" : "filter",
     "tags" : [ {
       "key" : "key1",
       "values" : [ "value1" ]
     } ]
   }
